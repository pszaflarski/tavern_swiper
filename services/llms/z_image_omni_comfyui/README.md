# Z-Image-Omni ComfyUI Service

Commercially compliant (Apache 2.0) OpenAI-compatible image generation and multi-reference restyling using Tongyi-MAI Z-Image Single-Stream Diffusion Transformer.

## Features
- **Scalable Single-Stream DiT (S³-DiT):** Direct joint image-text-latent attention modeling.
- **Multi-Reference Restyling:** Denoises a lifestyle target scene while injecting the canonical facial identity without 2D face seam lines.
- **Zero-Trust Auth:** Enforces Bearer token verification against `IMAGE_API_KEY`.
